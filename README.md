# Tarea 2 - Control de Versiones con Git y GitHub

## Descripción

Este repositorio contiene una página web desarrollada con HTML y CSS como parte de una práctica académica orientada al aprendizaje de herramientas de control de versiones. Durante el desarrollo se aplicaron conceptos fundamentales de Git y GitHub, incluyendo el uso de ramas, commits, integración de cambios y resolución de conflictos.

## Propósito del proyecto

El objetivo principal es comprender y aplicar un flujo de trabajo similar al utilizado en entornos profesionales de desarrollo de software. Para ello se implementó una rama principal estable, ramas secundarias para el desarrollo de nuevas características y cambios de diseño, así como procesos de integración mediante Pull Requests.

## Metodología de trabajo

El desarrollo se llevó a cabo siguiendo las siguientes etapas:

* Creación del repositorio en GitHub.
* Desarrollo de la estructura principal del sitio web.
* Implementación de una rama principal denominada `main`.
* Creación de la rama `dev` para nuevas funcionalidades.
* Creación de la rama `diseno` para modificaciones visuales.
* Registro de cambios mediante commits descriptivos.
* Simulación de revisión de código utilizando Pull Requests.
* Resolución de conflictos generados al modificar los mismos archivos en diferentes ramas.
* Integración final de los cambios en la rama principal.

## Estructura de ramas

* **main:** versión estable y final del proyecto.
* **dev:** desarrollo de nuevas características.
* **diseno:** ajustes visuales y estilos CSS.

## Ejemplos de commits realizados

* Creación inicial de la página web.
* Incorporación de estilos principales.
* Actualización de la documentación del proyecto.
* Integración de cambios de desarrollo.
* Resolución de conflicto entre ramas.
